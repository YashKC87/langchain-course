# Patch Management SOP

## Purpose
Keep Digital Workplace endpoints within approved patch SLAs.

## SLAs
- Critical security patches: <= 7 days
- Important patches: <= 30 days
- Feature updates: follow ring deployment calendar

## Remediation
1. Trigger available quality updates from Windows Update for Business.
2. Reboot during the user's maintenance window.
3. Verify patch age drops below policy threshold.
4. Re-run vulnerability scan attestation.
